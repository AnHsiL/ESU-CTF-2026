### MT 19937
Mersenne Twister 19937 是一種偽隨機數生成器，Python 的 `random` 模組預設使用它
MT 19937 的週期長度為 $2^{19937}-1$ ，並且由 624 個 32-bit 整數組成，產生的流程為：
1. **初始化**：seed 初始化 624 個 32-bit state
2. **Twist**：把目前 state 混合，產生下一批 state
	1. 取出相鄰兩個數值的位元並合併：`目前數值的最高 1 bit` + `下一個數值的低 31 bits`
	2. 右移一位，若最低位元為 1：與常數 `0x9908b0df` 進行 XOR
	3. 重設 index = 0，代表新一輪的狀態已更新
3. **Tempering**：每呼叫一次 MT19937 的 `rand()`  就取下一個 state 進行 Tempering
   ```python
	  y ^= y >> 11
	  y ^= (y << 7)  & 0x9d2c5680
	  y ^= (y << 15) & 0xefc60000
	  y ^= y >> 18
   ```
	輸出 32-bit 亂數
#### 攻擊方法
1. 拿到 624 個連續的 32-bit 亂數 -> 把 tempering 反過來 untemper 還原成 states
2. 將 states 給 MT 19937 演算法產生下一個亂數

## 解題
1. 觀察題目和 source code，發現：
	- `getrandbits(128)` 每次產生 4 個 32-bit 的亂數 -> 只需蒐集 $624 / 4 = 156$ 個亂數
	- 標題是 19937 -> 使用 [[#MT 19937|MT19937]] 亂數生成法
	- 可以獲取無數個連續的亂數，**目標**：預測下一個亂數
2. 蒐集 $156$ 個亂數，每個都 untemper 成 states
   ```python
	MASK32 = 0xffffffff
	
	def rotateR(y, shift, mask=MASK32):
	    # MT19937 是 32-bit，反覆約 ceil(32 / shift) 次就能完全還原
	    x = y
	    for _ in range(32 // shift + 1):
	        x = y ^ ((x >> shift) & mask)
	    return x & MASK32
	
	def rotateL(y, shift, mask):
	    x = y
	    for _ in range(32 // shift + 1):
	        x = y ^ ((x << shift) & mask)
	    return x & MASK32
	
	def untemper(out):
	    state = rotateR(out, 18)
	    state = rotateL(state, 15, 0xefc60000)
	    state = rotateL(state, 7, 0x9d2c5680)
	    state = rotateR(state, 11)
	    return state
   ```
1. 利用「已知 state 可以透過 `twist()` 產生下一個亂數」的特性，把 states 交由 MT 19937
   -> 寫 MT19937 腳本：~~叫 GPT 寫~~
   ```python
	class MT19937:
		def __init__(self, seed):
			self.n = 624
			self.m = 397
		
			self.mt = [0] * self.n
			self.mt[0] = seed & 0xffffffff
			self.index = self.n
		
			for i in range(1, self.n):
				self.mt[i] = (
					0x6c078965 * (self.mt[i - 1] ^ (self.mt[i - 1] >> 30)) + i
				) & 0xffffffff
		
		def twist(self):
			for i in range(self.n):
				x = ( 
					(self.mt[i] & 0x80000000) | 
					(self.mt[(i + 1) % self.n] & 0x7fffffff) 
				)
		
				xA = x >> 1
				if x & 1:
					xA ^= 0x9908b0df
		
				self.mt[i] = self.mt[(i + self.m) % self.n] ^ xA
			self.index = 0
		
		def rand(self):
			if self.index >= self.n:
				self.twist()
		
			y = self.mt[self.index]
			self.index += 1
		
			y ^= y >> 11
			y ^= (y << 7) & 0x9d2c5680
			y ^= (y << 15) & 0xefc60000
			y ^= y >> 18
		
			return y & 0xffffffff
   ```
