### Coppersmith’s Method
用來找「mod N 下的小根」
- 假設 $N$ 有因數 $b$ 滿足 $b \ge N^\beta, \; 0 < \beta \le 1$ 、多項式 $f(x)$ 最高次為 $\delta$
  如果 $f(x)$ 的根 $x_0$ 足夠小，可以在 $O(c\delta ^5 log ^9(N))$ 內找到所有 $x_0$  
  s.t. $f(x_0) \equiv 0 \; (mod \; b)$ 

## 解題
1. 觀察 source code，發現 `p0 = p - (p % 2**128)`，只剩高位元的資料，後 128 bits 被清除
   -> 目標：從已知的 `p0` 高位元還原出 `p` -> 求 `p` 的低 128 bits `x`
2. 將 `p0` 後面混亂的 128 bits 清零
   ```python
   k = 128
	p0 = (p0 >> k) << k
   ```
3. 設定 $f(x) = p0 + x$，在 [sega cell server](https://sagecell.sagemath.org/) 用 Coppersmith’s Method 求第一個根
   ```sega
   R.<x> = PolynomialRing(Zmod(N))
	f = p0 + x
	
	roots = f.small_roots(X=2^k, beta=0.4)
	print(roots[0])
   ```
